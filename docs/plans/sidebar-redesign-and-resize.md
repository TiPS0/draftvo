## 3. User Flow (Step-by-Step)

1. User views the application. The sidebar background is `#f9f8f7` and the center content background is `#ffffff`.
2. User hovers over the right edge of the sidebar. The mouse cursor changes to a column-resize (`<|>`) cursor, and a small "Resize Drag" component appears.
3. User clicks and drags the edge to resize the sidebar. The width is constrained between `250px` and `400px` and the layout adjusts smoothly.
4. User clicks the `<<` icon in the top right of the sidebar header. The sidebar collapses completely (or hides).
5. When the sidebar is hidden, an icon appears at the top-left of the main content. Clicking it expands the sidebar back to its previous width.
6. User clicks the "Inbox" button in the horizontal navigation row of the sidebar.
7. The app navigates to `/inbox`, which displays a centered success state ("You're all caught up") with an "Edit filter" button.
