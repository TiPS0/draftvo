## 3. User Flow (Step-by-Step)

1. User opens the Settings Modal.
2. User sees a "Logout" button at the bottom of the left sidebar.
3. User clicks the "Logout" button.
4. App shows a confirmation dialog (e.g., "Are you sure you want to log out?" with "Cancel" and "Logout" buttons).
